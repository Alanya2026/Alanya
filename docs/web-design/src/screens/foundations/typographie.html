Le mono signale ce qui est un identifiant, pas une phrase : numéros Alanya, codes, durées. Il donne aussi des chiffres de largeur fixe, ce qui empêche l'horodatage de faire vibrer la mise en page à chaque minute.

Repli si les webfonts ne chargent pas

Chaque famille est déclarée avec une pile de repli système complète. Si Google Fonts est injoignable, la mise en page tient à l'identique — seule la personnalité s'atténue. Aucun décalage de gabarit, aucun texte invisible.

--font-ui: 'Onest', ui-sans-serif, -apple-system, 'Segoe UI', Roboto, sans-serif;
--font-display: 'Instrument Serif', 'Iowan Old Style', Georgia, serif;
--font-mono: 'DM Mono', ui-monospace, 'SF Mono', Menlo, monospace;
